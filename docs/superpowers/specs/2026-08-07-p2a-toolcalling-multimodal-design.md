# P2-A: Tool-Calling & Multimodal — Design Spec

**Date:** 2026-08-07  
**Auteur:** Thomas (avec opencode)  
**Statut:** En review  
**Release cible:** v1.2.0

---

## 1. Vue d'Ensemble

Cette spec couvre les fonctionnalités P2-A pour transformer Godwit en une **plateforme agentic complète** avec support natif du tool-calling, de la vision multimodale, et du structured output.

### 1.1 Contexte

Le MVP (v1.0.0) + P1 (v1.1.0) ont livré :
- ✅ 13 endpoints core + 1 Anthropic-native
- ✅ Fallback/failover entre providers
- ✅ Usage tracking complet (9/9 providers)
- ✅ Cost layer consolidé
- ✅ MCP client (partiel — outils exposés mais pas de résolution automatique)
- ✅ SearXNG (web search backend)

**Ce qui manque pour l'agentic complet :**
- ❌ Tool-calling générique dans le DTO core (`tools`, `tool_choice`, `tool_calls`)
- ❌ Multimodal (images dans `ChatMessage.content`)
- ❌ JSON Schema / structured output
- ❌ Résolution automatique des tool calls (boucle agentic)
- ❌ Web search natif (OpenAI `web_search`, Anthropic `web_search`, Gemini `google_search`)

## 2. Fonctionnalités P2-A

### 2.1 Tool-Calling Générique (PRIORITÉ MAX)

**Problème :** Le DTO `ChatCompletionRequest` ne porte pas `tools`, `tool_choice`, ni `tool_calls` dans la réponse.

**Solution :** Étendre le DTO core et implémenter la résolution automatique.

#### 2.1.1 DTO Extensions

```rust
// crates/godwit-core/src/lib.rs

/// Tool definition for function calling
#[derive(Debug, Clone, Deserialize, Serialize)]
pub struct Tool {
    #[serde(default = "default_tool_type")]
    pub r#type: String,  // "function", "web_search", etc.
    pub function: FunctionDefinition,
}

fn default_tool_type() -> String { "function".to_string() }

#[derive(Debug, Clone, Deserialize, Serialize)]
pub struct FunctionDefinition {
    pub name: String,
    pub description: Option<String>,
    pub parameters: serde_json::Value,  // JSON Schema
    #[serde(default)]
    pub strict: bool,  // For OpenAI Structured Outputs
}

/// Tool choice: "auto", "none", "required", or specific function
#[derive(Debug, Clone, Deserialize, Serialize)]
#[serde(untagged)]
pub enum ToolChoice {
    Auto(String),  // "auto", "none", "required"
    Specific {
        r#type: String,
        function: ToolChoiceFunction,
    },
}

#[derive(Debug, Clone, Deserialize, Serialize)]
pub struct ToolChoiceFunction {
    pub name: String,
}

/// Tool call in response
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ToolCall {
    pub id: String,
    pub r#type: String,
    pub function: FunctionCall,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct FunctionCall {
    pub name: String,
    pub arguments: String,  // JSON string
}

/// Extended ChatCompletionRequest
pub struct ChatCompletionRequest {
    // ... existing fields ...
    
    /// Tools available for the model to call
    #[serde(default)]
    pub tools: Option<Vec<Tool>>,
    
    /// Controls which tools the model can call
    #[serde(default)]
    pub tool_choice: Option<ToolChoice>,
    
    /// Parallel tool calling (OpenAI 4.11+)
    #[serde(default)]
    pub parallel_tool_calls: Option<bool>,
}

/// Extended ChatCompletionResponse
pub struct ChatCompletionChoice {
    // ... existing fields ...
    
    /// Tool calls generated by the model
    #[serde(default)]
    pub tool_calls: Option<Vec<ToolCall>>,
}
```

#### 2.1.2 Résolution Automatique (Boucle Agentic)

```
┌─────────────────────────────────────────────────────────────┐
│  User Request (with tools)                                  │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│  Loop (max 4 iterations)                                    │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 1. Call model with tools                              │  │
│  │    - Append MCP tools from registry                   │  │
│  │    - Append web search tool (SearXNG) if enabled      │  │
│  └───────────────────────┬───────────────────────────────┘  │
│                          │                                  │
│                          ▼                                  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 2. Check response for tool_calls                      │  │
│  │    - If none → return final response                  │  │
│  │    - If present → continue                            │  │
│  └───────────────────────┬───────────────────────────────┘  │
│                          │                                  │
│                          ▼                                  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 3. Execute tool calls                                 │  │
│  │    - MCP tools → call MCP server via JSON-RPC         │  │
│  │    - web_search → call SearXNG API                    │  │
│  │    - function → reject (not registered)               │  │
│  └───────────────────────┬───────────────────────────────┘  │
│                          │                                  │
│                          ▼                                  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 4. Append tool results to conversation                │  │
│  │    - Add tool_result messages                         │  │
│  │    - Loop back to step 1                              │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

**Implémentation :**

```rust
// crates/godwit-api/src/agentic_loop.rs (new file)

pub struct AgenticLoop {
    mcp_registry: Arc<McpRegistry>,
    searxng_client: Option<SearxngClient>,
    max_iterations: u32,  // Default: 4 (configurable via app config)
}

impl AgenticLoop {
    pub async fn execute(
        &self,
        state: &Arc<AppState>,
        mut req: ChatCompletionRequest,
        resolved_model: &ResolvedModel,
    ) -> Result<ChatCompletionResponse, ApiError> {
        let mut conversation_history = req.messages.clone();
        let mut iteration = 0u32;
        
        loop {
            iteration += 1;
            if iteration > self.max_iterations {
                return Err(ApiError::BadRequest(
                    format!("Max agentic iterations ({}) exceeded", self.max_iterations)
                ));
            }
            
            // Append tools to request
            req.tools = Some(self.build_tool_list(&req.tools));
            req.messages = conversation_history.clone();
            
            // Call model
            let response = call_chat_model(state, resolved_model, req.clone()).await?;
            
            // Check for tool calls
            let Some(tool_calls) = response.choices.first()?.tool_calls.as_ref() else {
                // No tool calls → final response
                return Ok(response);
            };
            
            // Execute tool calls
            let tool_results = self.execute_tools(tool_calls).await?;
            
            // Append results to conversation
            conversation_history.push(ChatMessage::assistant_tool_results(tool_results));
        }
    }
    
    fn build_tool_list(&self, user_tools: &Option<Vec<Tool>>) -> Vec<Tool> {
        let mut tools = user_tools.clone().unwrap_or_default();
        
        // Append MCP tools
        tools.extend(self.mcp_registry.list_tools());
        
        // Append web search tool if SearXNG configured
        if self.searxng_client.is_some() {
            tools.push(Tool::web_search());
        }
        
        tools
    }
    
    async fn execute_tools(&self, tool_calls: &[ToolCall]) -> Result<Vec<ToolResult>, ApiError> {
        let mut results = Vec::new();
        
        for call in tool_calls {
            let result = match call.r#type.as_str() {
                "function" => {
                    // Check if MCP tool
                    if let Some(mcp_result) = self.mcp_registry.call_tool(&call.function).await {
                        mcp_result
                    } else {
                        return Err(ApiError::BadRequest(
                            format!("Unknown function: {}", call.function.name)
                        ));
                    }
                }
                "web_search" => {
                    self.searxng_search(&call.function.arguments).await?
                }
                _ => {
                    return Err(ApiError::BadRequest(
                        format!("Unknown tool type: {}", call.r#type)
                    ));
                }
            };
            results.push(result);
        }
        
        Ok(results)
    }
}
```

#### 2.1.3 Web Search Natif

**Support pour les tools web search des providers :**

| Provider | Tool Name | Implementation |
|----------|-----------|----------------|
| OpenAI | `web_search_preview` | Pass-through dans `tools[]` |
| Anthropic | `web_search_20250305` | Pass-through dans `tools[]` |
| Gemini | `google_search_retrieval` | Pass-through dans `tools[]` |
| **SearXNG (Godwit)** | `web_search` | **Implémenté** — appelle backend SearXNG |

**Quand un provider a son web search natif :**
- Godwit le passe tel quel au provider
- Le provider gère l'exécution
- Godwit ne fait rien de spécial

**Quand le provider n'a PAS de web search :**
- Godwit injecte `web_search` tool (SearXNG backend)
- Quand le modèle appelle ce tool, Godwit exécute via SearXNG
- Résultat injecté dans la conversation

### 2.2 Multimodal / Vision

**Problème :** `ChatMessage.content: String` ne peut pas porter d'images.

**Solution :** `ChatMessage.content: Option<Vec<ChatContent>>`

#### 2.2.1 DTO Extensions

```rust
// crates/godwit-core/src/lib.rs

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum ChatContent {
    Text {
        text: String,
        #[serde(default)]
        cache_control: Option<CacheControl>,
    },
    Image {
        image_url: ImageUrl,
        #[serde(default)]
        cache_control: Option<CacheControl>,
    },
    // Future: Audio, Video
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ImageUrl {
    pub url: String,  // data:image/... or https://...
    #[serde(default)]
    pub detail: Option<ImageDetail>,  // "low", "high", "auto"
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "lowercase")]
pub enum ImageDetail {
    Low,
    High,
    Auto,
}

#[derive(Debug, Clone, Default, Serialize, Deserialize)]
pub struct CacheControl {
    #[serde(default)]
    pub r#type: String,  // "ephemeral"
}

pub struct ChatMessage {
    pub role: String,
    /// Content can be:
    /// - String (backward compat, converted to Vec<ChatContent> with single Text)
    /// - Vec<ChatContent> (multimodal)
    #[serde(deserialize_with = "deserialize_content")]
    pub content: Option<Vec<ChatContent>>,
    // ... existing fields ...
}

fn deserialize_content<'de, D>(deserializer: D) -> Result<Option<Vec<ChatContent>>, D::Error>
where
    D: serde::Deserializer<'de>,
{
    #[derive(Deserialize)]
    #[serde(untagged)]
    enum ContentDe {
        String(String),
        Array(Vec<ChatContent>),
    }
    
    let content = Option::<ContentDe>::deserialize(deserializer)?;
    Ok(content.map(|c| match c {
        ContentDe::String(s) => vec![ChatContent::Text { text: s, cache_control: None }],
        ContentDe::Array(a) => a,
    }))
}
```

### 2.3 JSON Schema / Structured Output

**Problème :** Pas de support pour `response_format` JSON Schema.

**Solution :** Ajouter `response_format` au DTO + validation post-réponse.

#### 2.3.1 DTO Extensions

```rust
// crates/godwit-core/src/lib.rs

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ChatCompletionRequest {
    // ... existing fields ...
    
    /// Response format constraint
    #[serde(default)]
    pub response_format: Option<ResponseFormat>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum ResponseFormat {
    Text,
    JsonObject,  // JSON mode (no schema)
    JsonSchema {
        json_schema: JsonSchemaDefinition,
    },
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct JsonSchemaDefinition {
    pub name: String,
    pub schema: serde_json::Value,  // JSON Schema
    #[serde(default)]
    pub strict: bool,  // For OpenAI Structured Outputs
}
```

#### 2.3.2 Provider-Specific Translation

```rust
// openai.rs
let openai_response_format = match request.response_format {
    None => None,
    Some(ResponseFormat::Text) => Some(OpenAiResponseFormat::Text),
    Some(ResponseFormat::JsonObject) => Some(OpenAiResponseFormat::JsonObject),
    Some(ResponseFormat::JsonSchema { json_schema }) => {
        Some(OpenAiResponseFormat::JsonSchema {
            json_schema: OpenAiJsonSchema {
                name: json_schema.name,
                schema: json_schema.schema,
                strict: json_schema.strict,  // true = Structured Outputs
            }
        })
    }
};

// vllm.rs
let vllm_request = if let Some(ResponseFormat::JsonSchema { json_schema }) = &request.response_format {
    VllmRequest {
        guided_json: Some(json_schema.schema.clone()),
        ..default()
    }
} else {
    default()
};

// sglang.rs
let sglang_request = if let Some(ResponseFormat::JsonSchema { json_schema }) = &request.response_format {
    SglangRequest {
        json_schema: Some(json_schema.schema.clone()),
        ..default()
    }
} else {
    default()
};

// llama_cpp.rs
let llama_request = if let Some(ResponseFormat::JsonObject) = &request.response_format {
    LlamaCppRequest {
        format: Some("json".to_string()),
        ..default()
    }
} else if let Some(ResponseFormat::JsonSchema { json_schema }) = &request.response_format {
    // Convert JSON Schema to GBNF grammar (complex, use fallback)

        format: Some("json".to_string()),
        grammar: json_schema_to_gbnf(&json_schema.schema),  // Best effort
        ..default()
    }
} else {
    default()
};
```

#### 2.3.3 Validation Post-Réponse

```rust
// crates/godwit-api/src/response_validation.rs (new file)

use jsonschema::JSONSchema;

pub fn validate_response(
    response: &ChatCompletionResponse,
    response_format: &Option<ResponseFormat>,
) -> Result<(), ApiError> {
    let Some(ResponseFormat::JsonSchema { json_schema }) = response_format else {
        return Ok(());  // No validation needed
    };
    
    let content = response.choices.first()
        .ok_or(ApiError::BadRequest("No choices in response".to_string()))?
        .message.content.as_ref()
        .ok_or(ApiError::BadRequest("No content in response".to_string()))?;
    
    // Parse content as JSON
    let json_value: serde_json::Value = serde_json::from_str(&content[0].as_text()?)
        .map_err(|e| ApiError::BadRequest(format!("Invalid JSON: {}", e)))?;
    
    // Validate against schema
    let schema = JSONSchema::compile(&json_schema.schema)
        .map_err(|e| ApiError::Core(PasteurError::Config(format!(
            "Invalid JSON Schema: {}", e
        ))))?;
    
    let result = schema.validate(&json_value);
    if let Err(errors) = result {
        let error_msgs: Vec<String> = errors.map(|e| e.to_string()).collect();
        return Err(ApiError::BadRequest(format!(
            "Response does not match schema: {}",
            error_msgs.join(", ")
        )));
    }
    
    Ok(())
}

// Usage in agentic loop
let response = call_chat_model(...).await?;
validate_response(&response, &req.response_format)?;
```

## 5. Critères de Succès

### 5.1 Tool-Calling

- [ ] `tools`, `tool_choice`, `tool_calls` dans le DTO core
- [ ] Résolution automatique MCP tools (via `McpRegistry`)
- [ ] Résolution automatique web search (via SearXNG)
- [ ] Boucle agentic max 4 itérations (configurable dans `AppConfig.agentic.max_iterations`)
- [ ] Tests : MCP resolution, web search resolution, max iterations

### 5.2 Multimodal

- [ ] `ChatContent` enum (Text, Image)
- [ ] `ChatMessage.content: Option<Vec<ChatContent>>`
- [ ] Backward compat : String → Vec<ChatContent>
- [ ] Provider adapters : OpenAI, Anthropic, Gemini
- [ ] Tests : parsing multimodal, image encoding

### 5.3 JSON Schema

- [ ] `response_format` dans le DTO core (Text, JsonObject, JsonSchema)
- [ ] Provider-specific translation (OpenAI strict, vLLM guided_json, etc.)
- [ ] Validation post-réponse avec `jsonschema` crate
- [ ] Tests : validation passe/échoue, provider translation

## 6. Risques & Mitigations

| Risque | Impact | Mitigation |
|--------|--------|------------|
| Boucle infinie | Coût explosif | Max 4 itérations, logging |
| Tool call échoue | Conversation bloquée | Retry 1x, puis erreur |
| Image trop grande | Timeout provider | Validation taille avant envoi (max 10MB) |
| JSON Schema invalide | Erreur validation | Retry sans schema, ou erreur client |
| Guided decoding lent | Latence +20% | Timeout, fallback sans guided |
